## Описание файлов

### Документация

- **README.md** - Основная инструкция по использованию проекта
- **QUICKSTART.md** - Краткое руководство по быстрому запуску
- **TOPOLOGY.md** - Подробная схема сети, IP-адресация и проверка

### Скрипты настройки

#### ISP/setup.sh
- Настройка сетевых интерфейсов (ens33, ens34, ens35)
- Включение IP forwarding
- Настройка NAT через iptables
- Маршрутизация между HQ и BR

#### HQ-RTR/setup.sh
- Настройка интерфейсов к ISP и внутренней сети HQ
- Включение IP forwarding
- Установка FRR для маршрутизации
- Настройка статических маршрутов

#### HQ-SRV/setup.sh
- Настройка статического IP (10.0.0.2/24)
- Установка и настройка DNS (BIND) - зона hq.demo.local
- Установка и настройка DHCP (диапазон 10.0.0.10-50)
- Установка и настройка веб-сервера Apache
- Настройка firewall

#### HQ-CLI/setup.sh
- Настройка получения IP по DHCP
- Установка базовых утилит
- Настройка firewall

#### BR-RTR/setup.sh
- Настройка интерфейсов к ISP и внутренней сети BR
- Включение IP forwarding
- Установка FRR для маршрутизации
- Настройка статических маршрутов к HQ

#### BR-SRV/setup.sh
- Настройка статического IP (172.16.0.2/24)
- Установка и настройка DNS (BIND) - зона br.demo.local
- Установка и настройка DHCP (диапазон 172.16.0.10-50)
- Установка и настройка веб-сервера Apache
- Настройка firewall

## Особенности реализации

### Для РЕД ОС 8
- Используется `dnf` для установки пакетов
- Конфигурация сети через `/etc/sysconfig/network-scripts/`
- Управление сервисами через `systemctl`
- Firewall через `firewalld`
- Маршрутизация через FRR (Free Range Routing)

### Автоматизация
- Все скрипты идемпотентны (можно запускать повторно)
- Автозапуск сервисов через systemd
- Сохранение настроек после перезагрузки
- Проверка прав root перед выполнением

### Безопасность
- Настройка firewall на всех машинах
- Открыты только необходимые порты
- DNS forwarders на внешние серверы (8.8.8.8, 8.8.4.4)
