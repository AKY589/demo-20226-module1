# ДЕМО-2026 Модуль 1 - Автоматизация настройки

Автоматические скрипты для настройки виртуальных машин демоэкзамена по специальности "Сетевой и системный администратор".

## Структура проекта

```
module 1 problem solving/
├── ISP/          # Интернет-провайдер
├── HQ-RTR/       # Маршрутизатор главного офиса
├── HQ-SRV/       # Сервер главного офиса
├── HQ-CLI/       # Клиент главного офиса
├── BR-RTR/       # Маршрутизатор филиала
└── BR-SRV/       # Сервер филиала
```

## Требования

- ОС: РЕД ОС 8
- Права: root или sudo
- Интернет: для установки пакетов (на этапе настройки)

## Инструкция по использованию

### На каждой виртуальной машине:

1. Склонируйте репозиторий:
```bash
git clone https://github.com/ваш-username/demo-2026-module1.git
cd demo-2026-module1
```

2. Перейдите в папку соответствующей машины и запустите скрипт:

**Для ISP:**
```bash
cd ISP
sudo bash setup.sh
```

**Для HQ-RTR:**
```bash
cd HQ-RTR
sudo bash setup.sh
```

**Для HQ-SRV:**
```bash
cd HQ-SRV
sudo bash setup.sh
```

**Для HQ-CLI:**
```bash
cd HQ-CLI
sudo bash setup.sh
```

**Для BR-RTR:**
```bash
cd BR-RTR
sudo bash setup.sh
```

**Для BR-SRV:**
```bash
cd BR-SRV
sudo bash setup.sh
```

3. После выполнения скрипта перезагрузите машину:
```bash
sudo reboot
```

4. После перезагрузки все настройки будут применены автоматически.

## Что делают скрипты

- Настраивают сетевые интерфейсы (IP-адреса, маски, шлюзы)
- Устанавливают необходимые пакеты (bind, dhcp-server, httpd и т.д.)
- Применяют конфигурации сервисов
- Настраивают автозапуск сервисов при загрузке
- Настраивают маршрутизацию
